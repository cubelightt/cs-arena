# CS Arena 更新日志

## v1.0（2026-09-27）

### 比赛与房间

- ArenaMatch 接管自定义竞技与单挑对决的开赛、赛中事件和赛后结算；支持 BO1 / BO3、拼刀选边、竞技加时与战术暂停
- 比赛结束后房间自动恢复为等待状态；BO3 比赛页展示全部地图，赛后加入倒计时清场提示
- 房间新增「保存 Demo」开关，可按场决定是否录制录像；单挑对决新增局中回合进度提示
- 管理员可分别控制自定义竞技、单挑对决和增强人机三种建房模式；选图名称统一为「BP选图」

### 管理与部署

- 管理面板新增主机概况、游戏更新任务、按组维护、实例新建与删除，以及实例编辑和批量启停
- 录像支持定期归档和手动立即归档；管理面板可预览录像归集与磁盘清理任务
- 平台发布版本统一为 v1.0；提供 WinUI 前端与后端的独立 Docker 镜像及 Docker Compose 部署说明

## Beta V0.2（2026-09-19）

### 界面焕新：全新 WinUI 版前端

- 采用 Windows 11 / Fluent 设计语言的整体改版：浅色 / 深色主题（默认跟随系统）、侧边导航栏、通知条、进度环等完整控件体系，功能与旧版对齐
- 地图卡片改为 HLTV 比赛版式
- 比赛页改版
- 等待服务器初始化的提示条新增动态进度环
- 首页精简

### 单挑对决（1v1）完整玩法

- **对决类型**：长枪决斗（默认）/ 手枪决斗 / 狙击决斗 / Solo 三项
- **回合局数可配**：1~101 的奇数（默认 31 回合 16 胜）
- **地图池选择**：总竞技图池 / 单挑图池二选一（默认单挑图池），单挑房选图方式锁定为直接选图
- **每回合换边**：自制 Arena 服务器插件上线——固定队伍身份、奇数回合轮换出生点，记分牌 / MVP / 横幅 / 平台战绩修复
- **局内选枪**：`.guns`呼出菜单挑选武器，每回合自动装备所选武器与护甲
- 拼刀选边全模式默认关闭；单挑房设置精简

### 社区地图（创意工坊）

- 管理面板一键下载工坊地图，自动判定下载完成，全部比赛实例即时共享
- 社区图缩略图：上传 / 更换 / 删除，地图卡与列表直接显示
- 支持「本地自维护社区图」：剥离工坊图自带的脚本与开局配置，地图规则完全由平台接管

### 房间与比赛功能

- **友军伤害开关**（默认开启）：关闭后队友免疫子弹伤害；手雷、燃烧弹等投掷物仍会致伤（开局有提示）
- **开局公告**：比赛开始瞬间向全员播报拼刀选边 / 友军伤害状态
- **局内 ID**：玩家可设置仅本房间生效的对局内显示名（房间开关 + 右键「修改ID」弹窗，管理员可修改任意玩家）；玩家卡片显示自定义 ID
- **非名单观战**：比赛进行中允许不在名单内的玩家进服观战（全局开关，默认关闭，受剩余席位限制）
- **就位规则优化**：开赛条件改为两队全员就位；发布自维护版 MatchZy——按每队名单人数判定就绪，3v4 等人数不等房间不再需要手动 `.forceready`
- **实例最大玩家数可配**：管理面板设全局默认、房间可覆盖（管理员专用），开赛自动生效并参与容量校验
- 比赛结束自动清理实例侧比赛中间产物（回合备份 / 强制名文件等），比赛配置归档、日志外移，实例目录不再无限膨胀

### 体验优化与修复

- 房间设置新增「更多设置」弹窗
- 观战席修复与收敛：1 席居中显示、席位数正确生效；选项收敛为 0~5，0 = 禁止观战
- 增强人机房顶部显示「测试阶段」提示横幅
- 修复房主离开 / 断线时进行中比赛不结束、导致实例被永久占用的问题
- 一批界面细节修复（下拉框焦点环、文字对比度、数字框对齐、登录失败提示等）

## Beta V0.1（2026-08-13）

### 平台基础

- Steam OpenID 登录 / SteamID 手动登录，管理员账号体系与超管权限
- 房间全流程：创建 / 加入 / 踢人 / 换位 / 房间配置（人数、密码、观战席、服务器选择）/ 开赛 / 强制结束 / 解散；大厅实时显示进行中的房间
- 两种比赛模式：5v5 自定义竞技与 1v1 单挑对决，支持拼刀选边开关
- 换位体系：跨队换位需双方确认（60 秒过期）、队长移交与自动补位、随机分队（可选择保留队长）
- 槽位级阵容管理：队内槽位号持久化、指定槽位换位、空洞保留、自动补位开关（房主可控）
- 断线保护：宽限期内重连不退房，超时自动退房 / 解散，宽限时长可在管理面板调整；加入 / 离开房间横幅与关页确认

### 地图与选图

- 地图池体系：总竞技图池（官方地图，可录入 / 改名 / 移除）+ 恒 7 张服役池；官方图与社区图统一管理
- 三种选图方式：BP 淘汰选图（BO1 六轮 Ban + 对方选边 / BO3 三图制含图三刀局）、直接选图、社区图模式
- 社区地图池：创意工坊地图独立管理，开赛前自动预加载

### 服务器与比赛

- 服务器组与多实例管理：实例清单、启停 / 重置 / 仅管理员分级；管理面板实例控制台（实时日志与命令下发）
- 开赛全自动编排：自动分配空闲实例 → 启动 → 下发比赛配置 → 比赛进入直播状态，失败自动回滚释放实例
- 多种桥接模式（本地模拟 / HTTP / 反向 WebSocket），生产环境主机无需开放额外端口
- 比赛数据（待后续完善）：实时比分、赛后战绩（比分 / 胜方 / 阵容 / 地图）、对局录像（demo）自动上传与 15 天清理、GOTV 转播
- 实例冷却：赛后自动冷却，录像到齐自动解除，强制结束兜底

### 增强人机模式

- 建房开启「增强人机」：B 队全员人机对抗真人队（A 队可补人机），人机以房间槽位伪玩家显示在阵容面板
- 人机管理：指定 / 随机 / 整支职业队添加，枪法部位与投掷物强度可调
- 人机就位固化：开赛前配置固化到主机，热身阶段全部命名人机即在场，无随机人机混入；仅限人机专用实例
